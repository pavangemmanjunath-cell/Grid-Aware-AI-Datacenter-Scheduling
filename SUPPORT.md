# Support

## Documentation

Start with the [README](README.md), then [docs/reproducibility.md](docs/reproducibility.md),
[docs/methodology.md](docs/methodology.md) and [webapp/README.md](webapp/README.md). The API is
self-documented at `/docs` when the backend is running.

## Questions

Use **GitHub Issues** with the *Research question* form for questions about the model or results. If
GitHub Discussions is enabled for the repository, general usage questions are welcome there.

## Bug reports

Use the *Bug report* issue form. Include version or commit, OS, the exact command and the full error
output. Please do not attach confidential or personal data.

## Feature requests

Use the *Feature request* issue form and describe the problem before the proposed solution.

## Research questions

Use the *Research question* form for methodology, assumptions, reproduction differences or extensions.
For questions about the paper itself, cite the section you are referring to.

## Security problems

Do **not** post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

Support is best-effort; there is no guaranteed response time.
